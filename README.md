# সময় খাতা (Android অ্যাপ)

ফোনে চালু করে রাখলে নিজে নিজে সময়ের রিমাইন্ডার দেয়।

- **১৫ মিনিটে ১টি বিপ**, **৩০ মিনিটে ২টি বিপ** (৪৫ মিনিটে ১টি, ৬০ মিনিটে ২টি, এভাবে চলতে থাকে)
- ফোন সাইলেন্ট বা ভাইব্রেট মোডে থাকলেও বাজে (অ্যালার্ম ভলিউমে)
- স্ক্রিন বন্ধ থাকলেও, অ্যাপ খুলে না রাখলেও চলে
- **কতক্ষণ চালু থাকবে** সেটা বেছে নেওয়া যায় (৩০ মিনিট থেকে ১২ ঘণ্টা, বা নিজে বন্ধ না করা পর্যন্ত)
- **রুটিন**: কোন কোন বারে, কটা থেকে কটা পর্যন্ত নিজে নিজে চালু হবে তা ঠিক করা যায়
- সময় শেষ হলে ৩টি বিপ দিয়ে নিজে বন্ধ হয়

## APK বানানোর দুটি উপায়

### উপায় ১: GitHub দিয়ে (Android Studio লাগবে না)

1. github.com এ একটি নতুন repository খুলুন (যেমন `somoy-khata`)।
2. এই ফোল্ডারের সব ফাইল সেখানে আপলোড করুন। `.github/workflows/build-apk.yml` ফাইলটিও থাকতে হবে।
   (ওয়েবে ফোল্ডার আপলোডে লুকানো `.github` ফোল্ডার না গেলে: Add file → Create new file, নাম দিন `.github/workflows/build-apk.yml`, আর এই ফাইলের লেখা পেস্ট করুন।)
3. repository-র **Actions** ট্যাবে যান, **APK বানান** বেছে **Run workflow** চাপুন।
4. ৩-৫ মিনিট পর সবুজ টিক এলে ওই run খুলুন, নিচে **somoy-khata-apk** নামে একটি ফাইল পাবেন। নামিয়ে জিপ খুললে `app-debug.apk` পাবেন।

### উপায় ২: Android Studio দিয়ে

1. Android Studio-তে **Open** দিয়ে এই ফোল্ডার খুলুন, Gradle sync শেষ হতে দিন।
2. মেনু থেকে **Build → Build Bundle(s) / APK(s) → Build APK(s)**।
3. APK থাকবে `app/build/outputs/apk/debug/app-debug.apk`।

## ফোনে ইনস্টল

1. `app-debug.apk` ফোনে নিন (USB, Google Drive, Telegram ইত্যাদি দিয়ে)।
2. ফাইলে চাপ দিলে “অজানা উৎস থেকে ইনস্টল” এর অনুমতি চাইবে, দিন।
3. ইনস্টল হলে অ্যাপ খুলুন, নোটিফিকেশনের অনুমতি দিন।
4. অ্যাপের নিচের দিকে **ব্যাটারি সীমা তুলে দিন** বোতাম চেপে অনুমতি দিন। এটা না করলে কিছু ফোন ব্যাকগ্রাউন্ডে অ্যাপ বন্ধ করে দেয়।

## ব্যবহার

- **চালু করুন** চাপলেই এখন থেকে গুনতে শুরু করবে।
- **১ বিপ শুনুন / ২ বিপ শুনুন** চেপে আগেই শব্দ চিনে নিন।
- রুটিনে সময় ও বার ঠিক করে **রুটিন চালু** করে দিলে প্রতিদিন নিজে নিজে চালু ও বন্ধ হবে।

## জানা সীমাবদ্ধতা

- **Do Not Disturb**: ফোনের DND মোডে যদি “শুধু অ্যালার্ম”-ও বন্ধ থাকে (Total silence), তখন বিপ বাজবে না। সাধারণ DND-তে অ্যালার্ম বাজে।
- অ্যালার্ম ভলিউম বাড়িয়ে নেয় অ্যাপ, কিন্তু ব্লুটুথ হেডফোনে সংযুক্ত থাকলে শব্দ সেখানে যাবে।
- ফোন রিস্টার্ট দিলে চলতে থাকা সেশন বন্ধ হয়ে যায়, তবে রুটিন নিজে আবার ঠিক হয়ে যায়।
- এটা debug-signed APK, নিজের ব্যবহারের জন্য। Play Store-এর জন্য নয়।
